# components/novedades/

Reservado para componentes compartidos de Novedad (tarjeta, badge de
urgencia, formulario de reporte) reutilizables entre
`screens/ggss-en-pauta`, `screens/ggss-libre` y `screens/supervisor`. Hoy
cada screen implementa su propia UI de novedades; extraer aquí cuando haya
duplicación real que lo justifique.
